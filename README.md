# Simple MVC CMS written in node.js and SQLite.

## INSTALL:
1. go to the config file and set your app path and database file location.
2. go to /admin/install.html and follow the wizard.
3. have fun!

## DB Scripts:
- `npm run db:init` creates the SQLite file and schema in `/db`.
- `npm run db:seed` creates schema and inserts default `index/header/footer` content if missing.
